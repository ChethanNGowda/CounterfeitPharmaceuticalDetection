# Counterfeit Pharmaceutical Detection - Project Cleanup Plan

## Policy Overview

This document classifies every major directory and file group within the repository according to the project's strict reproducibility and safety criteria:

- **KEEP**: Active source code, trained checkpoints, base model weights, official datasets, automated test suites, configuration, and essential documentation.
- **ARCHIVE**: Historical experiment logs, legacy data preparation/lineage utility scripts, or older training run artifacts that have been superseded by full-data training runs but retain provenance value.
- **DELETE**: Temporary cache files (`.pytest_cache`, `__pycache__`), ephemeral generated logs, and disposable scratch scripts that are confirmed unreferenced and 100% reproducible.
- **REASON**: Explicit rationale detailing source references, dependency verification, and safety considerations.

## Action Plan Execution

1. Ensure `.gitignore` explicitly prevents tracking temporary directories (`__pycache__/`, `.pytest_cache/`, `runs/`, `.env`).
2. Move historical data-prep utilities to `archive/` if appropriate, while ensuring all active scripts in `scripts/` and root CLI (`test.py`) remain functional.
3. Validate that every active model checkpoint in `ml/config.py` resolves to an existing file on disk with verified SHA256 checksums.
4. Execute the complete test suite before and after any file movement to guarantee zero regressions.
